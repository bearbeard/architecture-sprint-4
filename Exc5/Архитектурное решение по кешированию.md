# Анализ

### MES API

Внедрить кэш по модели Write-through для отображения самых актуальных заказов.  
Когда в MES заказ будет переведён в статус `MANUFACTURING_APPROVED` он будет добавляться в кэш и в БД для приоритетного отображения.

### Shop API

Внедрить кэш для отображения страниц со скидками, избранного пользователя, корзины пользователя

# Мотивация

Улучшение пользовательского опыта - пользователям удобно пользоваться сайтом компании, это положительно влияет на лояльность к компании.
Повышение быстродействия и отказоустойчивости приложения - снижается риск лавинообразного потока запросов от пользователей из-за задержек в получении контента.

# Предлагаемое решение

### Shop API
Предлагается внедрять клиентское кэширование через http-заголовки.
Это позволит распределить объёмы хранения кэшей на браузеры всех пользователей и кэшировать актуальные данные для каждого отдельно взятого пользователя.

### MES API

Приоритет здесь отдаётся консистентности данных. Поэтому выбрано серверное кэширование с использованием паттернов Write-through и Read-through.  
Это позволит обновлять данные как только поменяется статус заказа, а так же наполнять кэш при отсутствии там данных.  
Всем операторам должна одновременно поставляться одинаковая версия обновленных данных в статусе `MANUFACTURING_APPROVED`, это те заказы, которые можно уже брать в работу
