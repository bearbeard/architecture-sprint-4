# Планирование мониторинга

Для сбора метрик будет использоваться Premetheus. Для экспорта метрик рядом с каждым компонентом юудет развёрнут sidecar сервис для скреппинга метрик в prometheus.
Для алертов используем prometheus alertmanager, чтобы заранее узнавать о возможных проблемах в системе.

# Мотивация

Сбор метрик позволит понимать какие части системы тормозят бизнес процессы и принимать ссответствующие решения при дальнейшем планировании развития системы.
Например, мы можем получить алерт о том, что дисковое пространство хранилища 3d файлов подходит к концу и запланировать работы по его расширению. Это предотвратит сбой, при котром пользователи не смогут загуржать файлы, а бизнес перестанет получать заказы.

# Выбор подхода к мониторингу

Shop API - RED, USE для метрик хостов
Shop DB - USE (RAM, CPU, I/O, диски), метрики БД (запросы, индексы, размер БД, подключения, кэши)

3d files storage - USE, RED

rabbitMQ - метрики golden signals, метрики кол-ва запросов, dead letter, соотношение consumer/producer

MES API - RED метрики
MES DB - USE (RAM, CPU, I/O, диски), метрики БД (запросы, индексы, размер БД, подключения, кэши)

# Метрики

## RabbitMQ

Number of dead-letter-exchange letters in RabbitMQ - для отслеживания состояния потока запросов между MES API и CRM API
Number of message in flight in RabbitMQ - для понимания объёма трафика через брокер

## Shop API

Number of requests (RPS) for internet shop API - трафик пользователей, позволяет понять профиль нагрузки на приложение
CPU % for shop API
Memory Utilisation for shop API
Number of HTTP 500 for shop API - мониторинг ошибок, для реагирования на инциденты
Response time (latency) for shop API

## CRM API

Number of requests (RPS) for CRM API
CPU % for CRM API
Memory Utilisation for CRM API
Number of HTTP 500 for CRM API
Response time (latency) for CRM API

## MES API

Number of requests (RPS) for MES API
CPU % for MES API
Memory Utilisation for MES API
Number of HTTP 500 for MES API
Response time (latency) for MES API

## Shop DB

Memory Utilisation for shop db instance
Number of connections for shop db instance
Size of shop db instance

## MES DB

Memory Utilisation for MES db instance
Number of connections for MES db instance
Size of MES db instance

## S3

CPU % for S3 storage
Number of HTTP 500 for shop API
Memory Utilisation for S3 storage
Size of S3 storage
